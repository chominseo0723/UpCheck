# 검증 범위

기준: 2026-11-10, Studio 최종 설정 #14. 이 문서는 실제 AI 실행, 로컬 모의 검증, 외부 계정 접속을 구분합니다.

## Studio 사례 검증

- `evaluation/`에 PDF 8개·총 61페이지가 있습니다.
- 논리적 제출서류는 46건, 별도 안내문은 7건입니다. 서류 유형표 합계 53건과 PDF 페이지 수는 단위가 다릅니다.
- 문서 분류·누락·중복·다중 문서·불명확 등 제출 유형 ①~⑤를 포함합니다.
- 정답지는 `evaluation/answer.json`, 문서 단위 유형표는 `evaluation/유형표.xlsx`입니다.
- 최종 #14의 8개 사례를 실행해 `reason`을 제외한 고정 값 11개씩 총 88개가 정답지와 일치했습니다.
- `reason`은 뜻을 확인하는 설명 항목이며 문자열 완전 일치 88개에 포함하지 않습니다.
- Studio UI 표시 기준 실행 시간은 사례별 38~49초였습니다.

이는 해당 검증 실행의 결과입니다. 반복 실행의 동일성, 외부 심사의 재실행 점수, Gmail 왕복 지연 또는 대량 운영 성능을 보장하지 않습니다. 원래 운영 계정의 실메일·원문 로그·화면은 공개 저장소에 포함하지 않았습니다.

## 로컬 모의 검증

```bash
npm test
npm run check:build
```

| 검증 파일 | 확인하는 내용 |
| --- | --- |
| `tests/test.cjs` | 12키 파싱, 보수적 회신 결정, 제목·수신 대상 제한, 누적 보완·같은 이름의 중복 보존, 오래된 안내 억제 |
| `tests/privacy-test.cjs` | 계정 분리, 지정 레거시 계정만 이전, 계정 불일치 거부, 개인정보 확인, 이름 가림·HTML 이스케이프 |
| `tests/recovery-test.cjs` | 업로드·실행·조회 일시 실패, 재시도 한도, 발송 응답 유실, 저장 실패·재조회·최신 보완 우선 |
| `tests/settings-test.cjs` | 실행 중 처리 안내·자동 안내 저장, 안내문 ID 재사용, 실제 연결 변경 시 중지 요구, 잠금 해제 |
| `scripts/build.cjs --check` | 원본과 통합 파일의 일치, Apps Script 통합 코드 문법 |

테스트는 가상 메일·응답·시간·장애를 사용합니다. 실제 Gmail을 읽거나 메일을 보내지 않으며, 실제 Upstage 키·요금·실행 권한을 확인하지 않습니다. 일부 테스트가 `tests/mail-preview.html`을 만들지만 이 파일은 생성 결과로 Git에서 제외합니다.

공개 소스의 기존 관리자 이메일과 테스트 이메일은 `owner@example.com` 예시 값으로 바꿨습니다. 이는 기존 데이터 이전 대상을 익명 예시로 만든 것이며 다중 관리자 실행 방식이나 문서 판정 규칙을 바꾼 것은 아닙니다. 기존 운영 배포는 GitHub 게시만으로 수정되지 않습니다.

## 실제 운영 확인과 남은 조건

기존 운영 계정에서 정상 PDF 내용 완비와 확정 누락·중복의 보완 안내 발송, 보완 답장 처리와 보류 결과를 확인했습니다. 신규 HTML 회신의 최종 촬영과 외부 관리자 계정의 Google·Upstage 연결은 별도 확인 범위입니다.

외부 계정 전체에서 경고 없이 접속되는 상태는 아닙니다. Google 미검증 앱 화면과 기관 정책에 따라 연결이 제한될 수 있습니다. Studio 라이브러리는 최종 #14로 승인 요청했으며, 이 기준일에 공개 게시 승인이 완료됐다는 뜻은 아닙니다.

실사용 검증은 가상 자료로 정상·누락·중복·보완·불명확 사례를 각각 확인하고, 자동 발송 여부와 최신 답장 결과를 구분해 기록해야 합니다.
